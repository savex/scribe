# Fuzzing

Targets for the parsers that read untrusted bytes. Seeds in `corpus/<target>/` are generated by
`cargo run -p scribe-test-support --bin gen-fixtures`; libFuzzer adds its own findings next to them
locally (commit only minimized crash reproducers, as new fixtures).

| Target | Function |
|---|---|
| `tls_client_hello` | `scribe_enrich::tls::{detect_security, parse_sni, parse_client_hello}` |
| `dns_message` | `scribe_enrich::dns::parse_response` and `DnsCache::observe` |
| `quic_initial` | `scribe_enrich::quic::{decrypt_initial, crypto_frames, InitialReassembler}`; input is datagrams with a 2-byte length prefix each |
| `http_request` | `scribe_module_url::parse::request_url` (URL module) |

```sh
cargo install cargo-fuzz
cd fuzz && cargo +nightly fuzz run tls_client_hello -- -max_total_time=1800
```
