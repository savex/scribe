# Fuzzing

Targets for the parsers that read untrusted bytes. Seeds in `corpus/<target>/` are generated by
`cargo run -p scribe-test-support --bin gen-fixtures`; libFuzzer adds its own findings next to them
locally (commit only minimized crash reproducers, as new fixtures).

| Target | Function |
|---|---|
| `tls_client_hello` | `scribe_enrich::tls::{detect_security, parse_sni}` |
| `http_request` | `scribe_enrich::http::parse_request_url` |

Planned: `dns_message` (DNS answer parser), `quic_initial` (QUIC Initial SNI) once those parsers exist.

```sh
cargo install cargo-fuzz
cd fuzz && cargo +nightly fuzz run tls_client_hello -- -max_total_time=1800
```
